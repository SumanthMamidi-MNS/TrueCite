Tech stack, and why

Hybrid retrieval
Vector search catches paraphrase; BM25 catches exact statutory terms a paraphrase misses. RRF fuses by rank, not score — nothing to miscalibrate.
Structural chunking
Follows each document's own numbered sections and lettered clauses — a fixed‑token window would cut a legal clause in half.
Local model, API one env‑var away
Development needed hundreds of calls; a metered key would exhaust before deployment. One seam switches provider, proven identical both ways.
Fixed sequence, not multi‑agent
No planner decides what runs next. Same sequence every time — auditable, and a judge can trace exactly what happened.
