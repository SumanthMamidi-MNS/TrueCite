- 2026-09-12: Phases 2 through 7 built, tested, and completed in one continuous session (user authorized working through all phases with self-verification, checking in only at genuine blockers). Chose ChromaDB over Qdrant (already running in user's Docker) for Phase 2 — simplicity over infra the project doesn't need yet. No Anthropic API key configured, so Layers 2/5 and generation use a local Ollama model (Qwen 2.5 7B, picked over Gemma 2 2B and Llama 3.1 8B) instead of the Claude API the PRD specifies — explicit, user-approved, temporary substitution.
  Built: embeddings/indexing/retrieval (Phase 2), BM25 + RRF hybrid (Phase 3, gate: avg rank 1.67->1.27), confidence gate + claim verification (Phase 4), authority-based citation ranking + full generate.answer_query pipeline (Phase 5), a 16-question eval harness (Phase 6), and a Streamlit UI + README (Phase 7).
  This was not a smooth build — real bugs were found and fixed at every phase by actually running things and checking output, not assuming correctness: chunk-dilution in Section 3 hurt retrieval for the TK non-patentability clause (fixed by splitting lettered clauses, which itself needed two more fixes for content-loss and duplicate-ID bugs it exposed); a vocabulary gap between terse statutory language and natural-language questions that chunking alone can't fix (documented, not chased further); a Layer 2 verification reliability issue from local-model non-determinism (fixed with majority voting); an authority-sort bug that evicted relevant chunks from the candidate pool; a chunk-ID-mangling bug in generation (fixed with numbered labels); a retrieval window too narrow to reach a correctly-worded but low-ranked statutory clause; an authority-preference prompt instruction the model over-applied after that fix; and an eval script whose own ground truth was too narrow in places (corrected against actual chunk text, not loosened arbitrarily).
  Final Phase 6 numbers: unanswerable questions 5/5 correctly refused, 0/5 false answers (clean throughout all debugging). Answerable questions: 5/11 citation accuracy, 5/11 false-refusal rate, traced to a genuine local-7B-model extraction-quality limitation (verified directly, not assumed) rather than a further fixable pipeline defect — the concrete cost of the temporary Ollama substitution.
  UI smoke-tested end-to-end in a real browser (question -> pipeline -> cited answer rendered correctly). All 46 automated tests pass. Everything committed locally to branch `phase-1-corpus-chunking`, no remote/push (per earlier user instruction — commits stay local until the user asks to push).
